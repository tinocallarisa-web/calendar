Privacy Policy — Calendar Events Heatmap

Effective: 2025-08-01 · v1.0.0.0
✅ Short version: Calendar Events Heatmap makes no external network calls and sends no data anywhere. All processing happens inside Power BI on the user's machine.

1. Data We Collect

The Visual does not collect, store, or transmit any personal data or report data to TCViz or any third party.

The data fields processed by the Visual are:

  • Date — date column provided by the report author
  • Main Measure — numeric measure for heatmap coloring
  • Tooltip Measures — optional additional numeric measures
  • Event Name — optional text column for event badge labels
  • Event Category — optional text column for event color grouping
  • Holiday Name — optional text column for holiday labels

All of these values are provided by the Power BI host from the report's data model and are processed exclusively in-memory within the sandboxed browser environment of the Power BI renderer. They are not stored beyond the lifetime of the render call.

2. External Network Calls

The Visual makes no external network calls whatsoever. There are no:

  • Requests to TCViz servers
  • Analytics or telemetry pings
  • CDN or font loads from external URLs
  • API calls of any kind

All rendering is self-contained. Fonts used are system fonts available in the Power BI environment (Segoe UI, system-ui).

3. License Validation

License status (Free or Pro) is determined exclusively through the official Microsoft Power BI IVisualLicenseManager API provided by the Power BI host. This API call is handled by the Power BI runtime; the Visual receives only a boolean result (licensed or not) and does not perform any independent network requests for license validation.

4. Format Pane Settings

Visual format settings (colors, font sizes, display preferences) are stored within the Power BI report file (`.pbix`) by the Power BI platform itself, using standard Power BI `objects` storage. TCViz does not have access to these settings.

5. Third-Party Services

The Visual does not integrate with any third-party services. License purchase and management is handled by Microsoft AppSource and Microsoft Commerce. Refer to Microsoft's Privacy Policy for information about how Microsoft handles your account and billing data.

6. Children's Privacy

The Visual is a data visualization tool for business analytics. It is not directed at children and does not knowingly collect any information from children.

7. Changes to This Policy

We may update this Privacy Policy to reflect changes to the Visual. The effective date at the top of this page will be updated accordingly. Since the Visual collects no data, material changes that affect user privacy are unlikely.

8. Contact

Questions about this Privacy Policy: support@tcviz.com
