WHAT CHANGED IN 1.1.0.0
- Keyboard navigation (roving tabindex, arrows, Home/End, PageUp/Down, Enter, Escape,
  Shift+F10), ARIA grid semantics, high contrast.
- Conditional formatting: Day Color with fx rule on Main Measure. Dynamic format strings,
  report tooltips, bookmarks, allowInteractions.
- No licensing UI of our own: the Week lock icon and upgrade toast are gone. Free users
  trying a Pro option get Power BI's notifyFeatureBlocked / notifyLicenseRequired.
- Pro format cards and options visible to everyone, marked [Pro].
- Removed an unused "License Key" format property.
- Week view no longer reachable in Free via Default View.

LICENCE
IVisualLicenseManager only: getAvailableServicePlans() against Plan ID "calendar-tcviz",
once, after the first render. Active and Warning accepted; the 30-day plan trial resolves
as Active. isLicenseUnsupportedEnv / isLicenseInfoAvailable honoured (no prompt where the
licence cannot be read). No external calls; privileges is []. No innerHTML.

FREE VS PRO
Free: month view (1 month), heatmap, fx Day Color, 1 event per day, holidays, tooltips,
cross-filtering, keyboard, high contrast.
Pro: week view, 1-12 months, more events per day, event/label/button styling, category
colours.
