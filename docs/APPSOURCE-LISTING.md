## Long description

Calendar Events Heatmap is the only Power BI calendar that combines a KPI heatmap with
event badges in a single visual. See which days had the highest sales — and whether it
was a promotion, a campaign or a public holiday — without switching between visuals.

**Included in the free tier**

- Month calendar with heatmap colouring by any measure
- Event badges with automatic per-category colours and an in-visual legend
- Holiday overlay
- Tooltip measures, plus support for report tooltip pages
- Conditional formatting: colour individual days by a rule on your measure
- Dynamic format strings — currencies, percentages and DAX-driven formats are honoured
- Cross-page filtering, multi-select, bookmarks and the right-click context menu
- Fiscal calendars with a custom year-start month, and a configurable first day of week
- Full keyboard navigation and Windows high-contrast support

**Pro ($9.99/month — 30-day free trial)**

- 1 to 12 months side by side
- Week view
- Per-category event colours, fully configurable, up to 8 categories
- Configurable number of event badges per day
- Full format pane control

**Accessibility**

The calendar is a real grid. Tab enters it once and the arrow keys move within it; Enter
filters the report, Escape clears the selection, and Page Up/Page Down change month. Every
day announces its date, value, holiday and events to a screen reader. Under a
high-contrast theme the heatmap intensity is re-encoded as border weight, so nothing
depends on colour alone.

Perfect for retail, FMCG and marketing teams who need to correlate daily KPIs with
promotions, campaigns and seasonal events.

No external network calls. All data stays inside Power BI.
